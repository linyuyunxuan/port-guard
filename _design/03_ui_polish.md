# PortGuard 界面优化走查（2026-10-21 / v1.2.x）

本轮是**视觉层级与状态可信度**的走查，不改信息架构、不改业务流程、不动判定链。
基线：`_design/01_visual_direction.md`（视觉方向）、`_design/02_ux_spec.md`（交互规范）。
所有改动均落在 `gui/`，`core/` 与 `app/` 未触碰。

---

## 1. 视觉主题

「素白哨岗 Paper Watchtower」不变：白底 + 石墨字 + 单一靛蓝强调色，颜色只表达语义。
本轮只解决三件事：

1. **第一屏读不懂**：统计卡把「量」放在「是什么」之前，三张卡右侧整片空白。
2. **勾选不可信**：勾选态是纯色方块（工具条）与灰框深色像素勾（表格）两套视觉，
   用户看不出「这张表勾了哪些行」。
3. **最关键的健康态缺席**：Windows 防火墙是否真在过滤，只写在封禁页的一条警示里，
   而它是「已封禁」三个字成立的前提。

## 4. 组件规范

### 4.1 统计卡 `StatCard`

- 尺寸：`Expanding × 90`，内边距 18/14，行距 2。
- 结构：`圆点 + 标签`（上）→ `数值 + 单位`（下，单位底对齐）。
- 状态：数值与圆点同色（`set_color`）；计数为 0 时回落 `text_on_dark`，不染红
  （红色 0 是噪声，会稀释真正有数时的语义）。
- 用法：`StatCard("今日访问", "0", unit="次")`。

### 4.2 勾选框（两处，一套视觉）

| 场景 | 实现 | 尺寸 |
| --- | --- | --- |
| 工具条 / 对话框 | QSS `QCheckBox::indicator` | 16×16，圆角 3，选中填 `primary` + 白勾 |
| 表格勾选列 | `CheckMarkDelegate`（自绘） | 16×16，同一圆角与配色，绘制在单元格正中 |

- 白勾来源 `assets/check.png`（13×13），由 `tools/gen_ui_assets.py` 生成，可重复执行。
- 为什么必须落一个位图：QSS 不支持 SVG data URI，也画不了折线；item view 的勾选
  指示器由 delegate 用基础样式绘制，`QTableView::indicator` 不生效。
- 勾着却被禁用：保留勾形、底色降到 `border_strong`，变回空框会让人以为勾选丢了。

### 4.3 卡片与工具条

- `QFrame#panel`：白底、`1px border_light`、圆角 8。
- 卡片标题行：内边距 16/12/16/8，标题 `panel_title` 16/600 + 一句 `text_muted` 12.5。
- 卡片内工具栏：左右 16、行间距 8，与标题行同一条左基线。

### 4.4 分隔条 `QSplitter`

10px 透明手感区，悬停才显 `border` 色。1px 实线夹在两张白卡之间时会被读成表格边框。

## 5. 布局

- 页面外边距统一 24/16/24/12，控件间距 12，卡片内 16/8。
- **风险事件页**：`筛选行 + 批量行` 装进一张工具卡，中间 1px 分隔线 —— 两行性质不同
  （筛选是「看哪些」、批量是「改哪些」），但同属「对整张表做点什么」。
- **封禁管理页**：上下两块统一为卡片（`待确认的封禁建议（N）` / `封禁记录（N）`），
  各带标题行、筛选行、批量行；两块之间用 10px 透明分隔条。原来下方是裸工具栏 + 裸表格。
- **顶部状态条**：`防火墙 · 本机观察 · 权限`，顺序即「是否真在防护 → 在保护谁 → 能不能动手」。

## 6. 层级与深度

无阴影（QSS 不支持）。分层只靠三档明度：页面 `#F4F6FA` → 卡片 `#FFF` → 表头/抬升面
`#F8FAFC`；1px 线只给可交互对象与卡片边界。

## 7. 注意事项（踩过的限制）

- QSS 只支持单值 `border-radius`，无 `box-shadow` / `transition` / `letter-spacing`。
- 图片资源必须用**绝对路径**进 QSS：快捷方式启动时工作目录不是程序目录，
  相对路径会静默失效（已走 `core.config.resource_path`，打包后指 `_MEIPASS`）。
- 勾选框不要图省事「只改底色」：浅色主题下纯色方块与禁用色块无法区分。
- 表格勾选列的命中判定交给基类（点指示器切换），自绘只负责画，不接管鼠标。

## 8. 尺寸与输入

- 窗口最小 1240×720，默认 1440×900；截图按 1360×860 复核。
- 表格列宽为硬约束（无横向滚动）：有界内容给足不截断，无界内容（路径 / 命中规则 /
  原因）走 tooltip。
- 所有图标按钮 22×22（行内）/ 30×30（工具条），表格行高 34，表头随字号。

### 未完成 / 下一轮

   左侧 55%，卡片右半与页面下半都是空的。建议给内容列设 max-width（约 980px）居中，
   或把「标签 → 字段」改成两列网格。

   根因是固定列宽合计 1151 > 可用宽 1098，`请求` 作为唯一拉伸列只能拿到约 120px。
   需要重新量列宽（两栈字体差异 6~20%），或把方法做成徽章、路径独立一列。

5. **刷新缺少中间态**：只有空态 `EmptyState`，没有加载/刷新中的反馈。
