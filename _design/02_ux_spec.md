# PortGuard 体验规范 v1 · 布局 / 交互 / 无障碍

> 依据：`01_visual_direction.md`（令牌已定稿）、`_design/before/*.png`（真实离屏渲染）、7 个页面源码。
> 只改布局与呈现，**不动判定逻辑、不动技术栈**。
> 宽度核算基准：侧栏 200 + 页面内边距 24×2 + 竖向滚动条 10 → **可用宽 1360=1102 / 1200=942**。

## 0. 十个问题的一句话结论（先看这里）

| # | 问题 | 结论 |
|---|---|---|
| 1 | 13 列怎么救 | **砍到 10 列，永不横向滚动**。删「方法」（并入「请求」列前缀）、「大小」、「User-Agent」；三者仍在 tooltip + 详情对话框。风险列前移到第 2 列 |
| 2 | 数字列截断 | 时间/端口/状态/评分/ID/时长/日期一律 Consolas 12 + **右对齐**；最小宽 = `max(表头中文数×12, 最长值×7.2) + 20` |
| 3 | 标题区与工具条 | 三层固定：标题区 **56** / 工具条 **56** / 结果区；「共 N 条」在工具条**最右端**（11px muted），不单独占行 |
| 4 | 封禁页双表格 | **保留双表**（改主从/合并都要动业务关系，不采纳）。上区改「待办区」：0 条时折叠成 44px 一行，有数据 168~320 可拖拽；下区吃掉剩余高度 |
| 5 | 设置页 6 组 | 改 **3 个下划线 tab**（服务与采集 / 防护与告警 / 数据与离线库）。不上左侧二级导航（196+160 双层导航），不用两列栅格（表单变 Z 字阅读）。标签列 **128 右对齐** |
| 6 | 状态重复 | 顶部 44 条 = **持久健康态**（服务/观察/权限，可点击跳转）；底部 26 条 = **左瞬时消息 + 右 IP 库/定位库**；监控页删第 4 张「接收服务」卡 → **3 卡** |
| 7 | 风险三表达 | **表格内只留徽章**。取消整行风险底色（`LEVEL_BG` 在表格中停用）；行底色只表达 hover / 选中 / 斑马。徽章分级守死：high 及以下淡底红字、只有 critical 实底；**评分列与其余数字列保持 `text_primary` 不染色**（否则红色又变两处） |
| 8 | 行内按钮 | 每行 **1 个主操作 + 1 个常驻「⋯」**（QMenu 承载其余）。**不做悬停才显示**（见 P0-4 理由） |
| 9 | 空态/加载/失败 | 统一用已就绪的 `widgets.EmptyState`：自绘 14px 图标 + 标题 13/600 + 一句说明 + 可选 h28 按钮；表格容器内居中，上下 40 |
| 10 | 键盘与焦点 | 只 5 个快捷键：`Ctrl+1~7` 切页 / `Ctrl+F` 搜索 / `F5` 刷新 / `Ctrl+Enter` 主操作 / `Esc`。表格 `tabKeyNavigation=False` |

> 为什么这样切不丢信息：判断一次访问只需要「谁（IP+归属地）→ 打哪（端口+请求）→ 结果（状态+命中规则）→ 多严重（风险）」，这四组全在表内；被删的 **方法**（并入请求列，`GET /api/...`）、**大小**、**UA**、**摘要**、**防火墙规则名** 属于「查证细节」而非「一屏判断」信息，全部在 hover tooltip 与非模态详情对话框中一字不少，且从 13 列降到 10 列后每条记录少 3 次「这是哪一列的判断」。

## 5. 统一状态规范（文案已可直接落库）

**结构固定**：`图标 14（自绘）→ 标题 13/600 text_secondary（4~8 字）→ 说明 12 text_muted（1 句，句末不加句号）→ 可选按钮 h28 ghost/primary`。位置：表格容器内水平居中、上下 padding 40；整块空态不画边框、不加背景。

| 场景 | 标题 | 说明（一句） | 动作 |
|---|---|---|---|
| 监控·无流量 | 等待访问 | 接收服务已启动，18080 尚未收到上报 | 复制上报地址 |
| 监控·服务未启动 | 接收服务未启动 | 启动后业务系统才能把访问记录发到本机 | 去启动（跳设置页服务组并聚焦按钮） |
| 监控·筛选无结果 | 没有匹配记录 | 换个关键字或把范围改回「全部」 | 重置筛选 |
| 事件·无命中 | 暂无风险事件 | 当前规则未命中任何访问，这是正常状态 | —（不放假按钮） |
| 封禁·无建议 | 没有待确认建议 | 规则引擎未发现需要封禁的高危 IP | —（折叠成 44px 一行） |
| 封禁·无记录 | 尚无封禁记录 | 确认封禁后，记录会出现在这里 | 手动封禁 |
| 查询·未查询 | 尚未查询 | 输入 IP 后点查询，结果会显示在这里 | — |
| 日志·空 | 暂无日志 | 程序还没有输出，或当前筛选条件过窄 | 清空筛选 |

**加载**：文本式「正在加载…」(12 muted) + 保持表头可见；长任务（离线库）用 8px 进度条 + `[阶段] 说明` 一行，不弹模态、不遮罩。
**服务未启动**：顶部状态点点位 `text_muted` + 文案「接收服务 未启动」；受影响的页（监控）改用专用空态；**不弹对话框**。
**库未加载**：底部右「定位库 不可用」用 danger；监控/事件页归属地列显示「—」并 tooltip 写明原因；首次只在页面顶部出一条 info 横幅（可关闭），不弹 `QMessageBox`（现状 `_poll_geo` 弹窗要改成横幅）。
**无权限**：顶部「权限 普通权限」warning 点；**只在会失败的页面**（封禁管理、设置·封禁策略）出现带动作的横幅；其余页不重复；点「封禁」时仍先走提权确认（保留现有顺序）。
**失败**：表格顶部 1 行 danger 横幅「数据加载失败：<原因>」+「重试」；同一失败 10s 内不重复弹窗。

## 6. 键盘与焦点（只列必要项）

| 快捷键 | 作用域 | 行为 |
|---|---|---|
| `Ctrl+1…7` | 全局 | 切到第 N 个页面（与侧栏顺序一致，导航项 tooltip 显示） |
| `Ctrl+F` | 7 页 | 聚焦当前页搜索框并全选；再按 `Esc` 清空并回到表格 |
| `F5` | 事件/封禁/日志 | 刷新当前页数据（= 点「刷新」） |
| `Ctrl+Enter` | 事件/封禁建议 | 对选中行执行主操作（封禁 / 确认封禁），仍需确认框 |
| `↑ ↓ PgUp PgDn Home End` | 表格 | 移动选中行（`SingleSelection + SelectRows` 已满足） |
| `Enter` / 双击 | 表格 | 打开详情 |
| `Esc` | 对话框 | 取消（保留） |

**焦点顺序（每页一致）**：`侧栏导航 → 标题区右侧动作 → 工具条（搜索 → 各筛选 → 主操作 → 次要动作；计数不可聚焦）→ 结果区（表格/卡片）→ 页脚`。
**规则**：① 每个可聚焦控件必须有可见焦点（P0-5）；② 表格 `tabKeyNavigation=False`，Tab 一次就离开表格；③ 自定义控件（`ToggleSwitch`/`Dot` 容器）补 `setFocusPolicy(StrongFocus)` + `setAccessibleName`，开关需支持 Space 切换；④ 纯图标按钮（`⋯`）必须有 `setAccessibleName` + tooltip。

**无障碍清单（本轮）**：焦点可见（P0-5）｜颜色不作唯一通道（风险已有文字徽章，状态点旁必须有文字）｜数字列右对齐 + 等宽保证列内可比较｜表格内按钮 hit 区 ≥22×48（行高 30 内可接受；不追求触控尺寸）｜禁用态 3.06:1 只用于 disabled 且不可读区域不含关键信息｜对话框 `取消` 在左、`确认` 在右、默认焦点在取消（破坏性操作）｜正文与 muted 文案对比度沿用视觉方案实测值。
