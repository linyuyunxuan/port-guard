============================================================
 PortGuard 启动失败：没有找到可用的 Python 运行环境
============================================================

说明：判断标准不是「有没有装 Python」，而是「那个 Python 能不能
      import PySide2 或 PySide6」。这台机器上通常装了多个 Python，
      PATH 上的那个很可能没有装本项目的依赖。

上面 Tried: 后面列的就是逐个尝试过的位置，可以按下面对号入座。

------------------------------------------------------------
办法一：自动装（推荐）
------------------------------------------------------------
双击 install.bat           创建开发栈（Python 3.9+ / PySide6）
双击后回车即可，装完再双击 start.bat。

若这是要交付到 Server 2008 R2 的机器，请改用交付栈：
    install.bat delivery

------------------------------------------------------------
办法二：手动装交付栈（Python 3.8 + PySide2）
------------------------------------------------------------
在本目录的命令行里依次执行：

    py -3.8 -m venv envs\portguard38
    envs\portguard38\Scripts\python.exe -m pip install -r requirements.txt

装完双击 start.bat 即可，启动器会自动优先选中 envs\portguard38。

------------------------------------------------------------
办法三：直接指定解释器
------------------------------------------------------------
如果你已经知道哪个 Python 装了依赖，可以绕开启动器：

    "C:\目标环境\Scripts\python.exe" main.py

或者先跑环境自诊断，它会告诉你缺什么：

    "C:\目标环境\Scripts\python.exe" main.py --diag

------------------------------------------------------------
提示
------------------------------------------------------------
· 封禁功能需要管理员权限，请用 start_as_admin.bat。
· 启动失败时日志在 data\logs\portguard.log，日志里没有内容说明
  失败发生在日志系统初始化之前（通常是解释器/依赖选错了）。
