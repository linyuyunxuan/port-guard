PortGuard · 更新日志
================================================

版本号以包内 VERSION.txt、程序「关于」页、exe 文件属性与压缩包文件名为准，
四处应一致。本日志自 v1.9.2 起随交付包提供。


v1.9.5 · 首用与可信（2026-11-10）
------------------------------------------------
  权限与首启
    * 交付 exe 由 requireAdministrator 改为 asInvoker：默认普通权限启动
      （只读 / 观察模式），监控、风险、历史、IP 查询、规则、统计与导出
      全部可用，不再一启动就弹 UAC。写防火墙仍由用户主动触发提权
      （封禁管理页「以管理员身份重启」）；包内新增 start-as-admin.bat，
      供需要常驻完整模式的客户一键以管理员启动。
    * 顶栏「权限」改为可点，落到关于页新增的「权限与能力」栏，
      成为能力边界的唯一自助说明；总览健康分不再把观察模式算作扣分项。
    * 启动期定位库加载失败不再弹模态阻塞无人值守，改为状态栏常驻
      「定位库 读取失败」+ 设置页「重新加载定位库」自助重试；
      普通权限下仍显示防火墙关闭红条。开机自启改为观察模式、不弹 UAC。
  可信与可验收
    * 封禁账本读取失败不再静默按「未封禁」渲染：访问 / 事件 / 封禁三个
      列表页统一显示「封禁状态读取失败」持久横幅并提供「重试」动作。
    * 归属地「读取失败」与「查了没收录（未知）」分开显示；
      「待确认建议」空态改用统一空态组件。
  逐台运维
    + 设置页新增策略快照导出 / 导入（规则、黑白名单、策略设置）：
      导入前自动备份、失败可回滚，不含运行数据与本机凭据。
    + 操作审计页新增导出 CSV，额外带「主机名 / 程序版本」两列；
      审计面板保持只读，导出不影响留痕。
  说明
    - 本版未改动风险评分与封禁判定逻辑；界面以新增提示与入口为主。
    - 已知限制：exe 仍无 Authenticode 数字签名（需外部证书）、
      无应用内自动升级；许可 / 试用属商业授权范围，由采购文件约定。


v1.9.4 · 交付合规修订（2026-11-10）
------------------------------------------------
  交付物
    + 包内新增 NOTICE.txt、使用条款、完整性校验说明、部署 / 升级 / 卸载说明、
      逐文件 SHA256 校验清单、VERSION.txt 与更新日志。
    + 包内新增 LGPL v3、GPL v3、Apache-2.0 三份许可全文（licenses/）。
    + 打包脚本把上述材料列为交付包的固定组成，缺少任一材料即无法出包。
  对外口径
    * 修正 README / NOTICE 中关于界面依赖（交付栈为 PySide2 5.15.2.1，
      而非 PySide6）、离线库已随包附带、Webhook 可选出站、防火墙规则命名、
      以及历史测试基线的过期表述。
    * 关于页的第三方组件指引改为指向包内实际存在的 NOTICE.txt 与 licenses/。
    * 设置页「立即检查更新」明确为离线 IP 库检查，避免被误认为程序版本升级。
    * pyproject.toml 的包元数据版本与描述同步到当前交付版本。
    * docs/ 内历史评测报告标注为历史快照，不再作为当前版本基线。
  说明
    - 本版未改动风险评分、封禁判定、规则引擎与核心交互流程；界面仅调整文案。
    - 已知限制（当时）：exe 无 Authenticode 数字签名、全进程管理员权限、
      无应用内自动升级。其中「全进程管理员」已在 v1.9.5 解除，其余两项仍在，
      详见 03_INTEGRITY.txt 与 01_DEPLOY.txt 第六节。


v1.9.3 · 建议口径统一与界面精修（2026-11-10）
------------------------------------------------
    * 「待确认封禁建议」统计改为按 IP + 端口去重，排除已自动拦截与已处理的
      重复事件，与封禁管理页展示口径一致；计数为 0 时总览不再显示该行。
    * 设置 / 封禁管理 / 规则配置 / 关于页统一为「分组名 + 胶囊页签」，
      选中项蓝底白字。
    * 总览六张卡精修：标题锚点、主数字层级、明细块与实时流状态条可读性。


v1.9.2 · 管理界面缺陷修复（2026-11-10）
------------------------------------------------
    * 修复消息数量角标遮挡功能名称。
    * 自定义规则自动拦截的事件与待人工处理事件分开筛选与计数，
      状态栏改为按实际事件数显示自动拦截与待处理数量。
    * 封禁管理拆为「待确认建议」与「封禁记录」两个独立页签，
      到期 / 自动解封提示自动清理。
    * 设置页备份明细改为下拉选择，子菜单分组与层级统一。
