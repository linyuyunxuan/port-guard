PortGuard 端口访问防御工具 · 交付包先读我
================================================

本压缩包为免安装（解压即用）的 Windows 桌面程序。部署前请先读完本文件。


一、包内文件清单
------------------------------------------------
  PortGuard.exe          主程序（默认普通权限 / 观察模式，见 01_DEPLOY.txt）
  start-as-admin.bat     以管理员身份启动（需要写防火墙规则时使用）
  _internal/             程序运行库与只读资源，请勿改动或删除其中文件
  VERSION.txt            本包版本号（与「关于」页、exe 文件属性一致）
  NOTICE.txt             第三方组件与许可清单
  SHA256SUMS.txt         包内逐文件 SHA256 校验清单
  00_README.txt          本文件：交付清单与阅读顺序
  01_DEPLOY.txt          部署 / 升级 / 卸载 / 权限 / 离线环境 / 故障自查
  02_TERMS.txt           最终用户使用条款（使用前请先阅读）
  03_INTEGRITY.txt       完整性校验方法与发布者身份现状
  04_CHANGELOG.txt       与版本对应的更新日志
  licenses/              LGPL v3、GPL v3、Apache-2.0 许可全文

  压缩包外另附 PortGuard-v<版本>.zip.sha256，是整个压缩包的校验单，
  请与本压缩包一起保存、一起提供给最终使用方。


二、部署阅读顺序
------------------------------------------------
  1. 按 03_INTEGRITY.txt 校验压缩包完整性，并阅读发布者身份说明。
  2. 阅读 02_TERMS.txt 使用条款，确认使用环境已获授权。
  3. 按 01_DEPLOY.txt 解压到固定目录并直接启动（无需管理员、不弹 UAC）。
  4. 在程序「关于」页核对版本号，确认与 VERSION.txt、压缩包文件名一致；
     顶栏「权限」点开可查看当前能做什么、哪些动作需要管理员。
  5. 需要封禁 / 解封时，用 start-as-admin.bat 启动，或在封禁管理页点
     「以管理员身份重启」。首次使用请保持「人工确认后封禁」。


三、必须先知道的三件事
------------------------------------------------
  1. 本程序会创建 / 删除 Windows 防火墙入站规则。请仅在自有或已获书面授权
     的设备上使用，并先确认放行规则覆盖远程管理端口，避免把自己锁在外面。

  2. 默认以普通权限启动（观察模式）：查看采集、风险、历史、统计与导出
     都不需要管理员，也不会写防火墙。只有确认封禁 / 解封等写操作才需要
     提权，且每次都由你主动确认 UAC。企业批量部署前请先按
     03_INTEGRITY.txt 核验来源，并按 01_DEPLOY.txt 完成白名单评估。

  3. 卸载时防火墙规则与用户数据不会自动清除。必须按 01_DEPLOY.txt 的卸载
     步骤处理，否则服务器上会继续保留 PortGuard_Block_* 拦截规则与
     PortGuard_Allow_* 放行规则。


四、支持与反馈
------------------------------------------------
  程序内「关于」页列有作者与联系方式。提交问题时请先按 01_DEPLOY.txt 的
  「故障自查」生成自诊断报告，连同运行日志一起提供给支持方，可显著缩短
  定位时间。
